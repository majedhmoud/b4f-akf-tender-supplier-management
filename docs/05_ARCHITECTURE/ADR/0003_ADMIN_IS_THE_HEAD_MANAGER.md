# `admin` is the AKF head manager, not a technical administrator

The `admin` user is the head manager of the AKF. They approve committee members and register their accounts. For supplier sign-up, they accept the legally reviewed request without editing it. The platform creates the supplier account. A reader might expect "admin" to mean a technical system administrator; it does not, and no such user is currently defined.
